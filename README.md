# סידור עבודה (SidurAvoda)

תוכנה להכנת סידורי משמרות שבועיים לעובדים (Windows).

המאגר הזה משמש **שרת עדכונים**: כל גרסה חדשה מתפרסמת כאן בתיקייה releases, והקובץ latest.json אומר מה הגרסה האחרונה.
התוכנה בודקת בכל פתיחה אם יש גרסה חדשה, מורידה ומתקינה אותה. הנתונים במחשב לא משתנים.

התקנה: מורידים את הקובץ SidurAvoda-X.Y.Z.zip מהתיקייה releases (הגרסה האחרונה), פותחים את ה-zip
ומעתיקים את הקבצים לכונן שאינו C (למשל D:\SidurAvoda), ואז מפעילים את SidurAvoda.exe.
